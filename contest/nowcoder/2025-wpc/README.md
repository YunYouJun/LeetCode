## A

**链接**: https://ac.nowcoder.com/acm/contest/126837/A
**来源**: 牛客网

### 题目描述

2025年，TIT创意园和媒体港部分同事搬到了琶洲的腾讯广州大厦。

一开始，很多同学担心会因此影响不同团队间的办公合作效率。慢慢的，大家发现影响是，和小伙伴们约饭没那么方便了。

于是，微信群里常常出现这样的对话：今天吃饭吗？如果所有人都表示同意，那就出发吃饭了！

### 输入描述

在一行上输入两个整数 `a, b` (`1 ≤ a ≤ 500; 0 ≤ b ≤ a`)，表示这个微信群的总人数、群里同意今天一起吃饭的总人数。

### 输出描述

如果大家今天能一起吃饭，输出 `Yes`，否则输出 `No`。

### 示例1

**输入**:
```
3 3
```

**输出**:
```
Yes
```

## B

**链接**: https://ac.nowcoder.com/acm/contest/126837/B
**来源**: 牛客网

### 题目描述

Alice 和 Bob 收到一个长度为 `n`、仅由字符 `'A'` 和 `'B'` 构成的字符串 `s`，以及一个整数 `k`。

他们轮流进行操作，Alice 先手，双方均采取最优策略行事。Alice 的目标是在有限步内将字符串全部变为 `'A'`；如果 Alice 无法在有限步内达成目标，则 Bob 获胜。注意：只要在任意时刻（包括 Alice 的操作后、Bob 的操作前）字符串全为 `'A'`，Alice 即获得胜利。

双方操作如下：
- **Alice 的操作**: 选择 `s` 中的任意一个长度为 `k` 的子串，并将该子串中的所有字符都置为 `'A'`。
- **Bob 的操作**: 选择 `s` 中的任意一个长度为 `k` 的子串，并将该子串中的所有字符都置为 `'B'`。

**【名词解释】**
子串：从原字符串中，连续的选择一段字符（可以全选、可以不选）得到的新字符串。

### 输入描述

每个测试文件均包含多组测试数据。第一行输入一个整数 `T` (`1 ≤ T ≤ 2×10⁵`) 代表数据组数，每组测试数据描述如下：

第一行输入两个整数 `n, k` (`1 ≤ k < n; 1 ≤ n ≤ 2×10⁵`)，代表字符串长度和子串长度。

第二行输入一个长度为 `n`，由字符 `'A'` 和 `'B'` 组成的字符串 `s`，代表初始字符串。

除此之外，保证单个测试文件的 `n` 之和不超过 `2×10⁶`。

### 输出描述

对于每组测试数据，新起一行输出一个字符串，如果 Alice 获胜，则输出 `Alice`，否则输出 `Bob`。

### 示例1

**输入**:
```
6
5 2
AABAA
7 4
ABAABAA
6 1
BABBBB
4 1
AAAA
8 3
ABAABAAB
6 4
AAAAAA
```

**输出**:
```
Alice
Alice
Bob
Alice
Bob
Alice
```

**说明**:
对于第一组测试数据，Alice 可以直接对第三个字符（下标从 1 开始）所在的长度为 2 的子串（`"AABAA"`）执行操作，将其变成 `"AAAAA"`，此时整个字符串变为 `"AAAAA"`，Alice 胜利。
